# **App Name**: Jugnoo Transport Network

## Core Features:

- Driver Registration: Register drivers with relevant information (name, contact, license, etc.).
- Vehicle Registration: Maintain a database of registered vehicles (model, type, capacity, registration number).
- Customer Registration: Keep track of customers using the transport service (name, address, contact information).
- Route Management: Define and manage routes with key details (origin, destination, distance).
- Expense Tracking: Record expenses related to each trip including fuel, maintenance, toll taxes, and supplier costs. The LLM will act as a tool to recognize relevant types of expenses described in unstructured text, such as supplier costs.
- Reporting: Generate reports based on different filters such as vehicle, customer, driver, route, and supplier. Reports should present profit/loss margins as well.
- Data Editing: Enable editing of any incorrect data entry made in the registration or expense modules.

## Style Guidelines:

- Primary color: A strong, dependable blue (#4285F4) to instill trust and reflect logistics efficiency.
- Background color: Light blue-gray (#F0F4F8) offering a neutral backdrop to highlight key data.
- Accent color: Energetic green (#34A853) used sparingly for calls to action and highlighting profits.
- Headline font: 'Poppins', a geometric sans-serif font, used for a modern, clean presentation.
- Body font: 'PT Sans', a readable humanist sans-serif font, providing clarity and approachability.
- Consistent use of simple, easily recognizable icons representing each module (vehicle, driver, expenses, etc.).
- Tab-based navigation for the main sections: General, Expenses, Edit, Report, and Close. Each section uses clear and concise layouts for easy data entry and review.
- Subtle transitions and animations for feedback on interactions, such as successful form submissions or report generation.
